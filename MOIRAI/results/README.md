# Results: MOIRAI forecast of BC Hydro load, 1-7 January 2026

Generated by running `../MOIRAI_Jan2026_Week1.ipynb` in Colab (step 9 saves these files).

| File | What it shows | How to read it |
|---|---|---|
| `forecast_vs_actual.png` | Main result: hourly load for 1-7 Jan 2026 | Grey = actual, orange = MOIRAI forecast, orange shading = 80% range (P10-P90), blue dashed = same week last year. The closer orange is to grey, the better. |
| `history.png` | Daily average load 2016-2025 | The data MOIRAI read before forecasting. |
| `scores.csv` | Accuracy of MOIRAI vs the "same week last year" baseline | MAE, RMSE, Max error in MW and MAPE in %. Lower is better. |
| `daily_comparison.csv` | Average load per day: actual, MOIRAI, last year, MOIRAI error % | Positive error means MOIRAI forecast too high. Expect the biggest error on 1 Jan (holiday). |

**Key notes**
- MOIRAI 2.0 is used zero-shot (no training), reading the last 48 weeks of hourly load.
- It sees only load numbers, with no weather and no calendar, so holidays like New Year's Day are harder.
